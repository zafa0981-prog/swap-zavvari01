# سوآپ زواری — اپ اندروید

این پوشه یک پروژه کامل است. فایل APK را GitHub به‌صورت خودکار و رایگان برایت می‌سازد.

## ساخت APK (یک‌بار)
1. در github.com حساب رایگان بساز و یک مخزن جدید (ترجیحاً Private) بساز.
2. از کامپیوتر: Add file ← Upload files، و **همه** محتویات این پوشه را بکش و رها کن
   (حتماً پوشه مخفی `.github` هم باشد؛ اگر نمی‌بینی، نمایش فایل‌های مخفی را روشن کن). Commit بزن.
3. تب Actions ← «Build APK» ← Run workflow (حدود ۵ تا ۱۰ دقیقه).
4. وقتی سبز شد، روی اجرا کلیک کن ← پایین صفحه بخش Artifacts ← `swap-zavari-apk` را دانلود کن.
5. فایل zip را باز کن و `app-debug.apk` را به گوشی منتقل و نصب کن
   (اگر خواست، «نصب از منابع ناشناس» را برای همان برنامه اجازه بده).
6. اگر مرحله‌ای قرمز شد، ۳۰ خط آخر لاگ همان مرحله را برای من بفرست.

## استفاده
- برنامه به‌صورت پیش‌فرض آزمایشی (Paper) با ۲۱ USDT مجازی و قیمت زنده است: «شروع ربات» را بزن.
- معامله واقعی: در بخش کیف پول، Project ID رایگان را از dashboard.reown.com بگیر و ذخیره کن،
  «اتصال به Trust Wallet» را بزن و سپس «معامله واقعی» را روشن کن. هر تراکنش فقط پس از تأیید تو در برنامه
  و تأیید نهایی داخل Trust Wallet ارسال می‌شود.
- اول با سقف خیلی کم (مثلاً ۱ USDT) امتحان کن. سود تضمین‌شده‌ای وجود ندارد.

## اجرا در پس‌زمینه
- با «شروع ربات»، اپ یک سرویس پیش‌زمینه (با اعلان دائمی) راه می‌اندازد تا با خاموش‌شدن صفحه یا رفتن به برنامه دیگر هم کار کند.
- اجازه اعلان را بده و در پنجره‌ای که باز می‌شود «بدون محدودیت باتری / Don't optimize» را تأیید کن؛ بدون این، اندروید ممکن است ربات را در پس‌زمینه متوقف کند.
- در برخی گوشی‌ها (شیائومی، سامسونگ، هواوی، اوپو و ...) باید در تنظیمات گوشی هم برای این اپ «اجرای خودکار / Autostart» و «بدون محدودیت پس‌زمینه» را روشن کنی.
- اگر اپ را از لیست برنامه‌های اخیر Swipe کنی یا گوشی خاموش شود، ربات می‌ایستد؛ با باز کردن دوباره اپ ادامه پیدا می‌کند.
- ربات فقط تا وقتی کار می‌کند که اینترنت وصل باشد.
